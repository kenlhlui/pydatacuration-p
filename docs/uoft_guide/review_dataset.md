Review a dataset
===

1. **Start a review**: Start the curation tool if it isn't running (see [Restart the tool](./restart.md)), then open `http://localhost:9005` in your web browser. Click the '📁New dataset' box. Fill in the form, including the dataset DOI and the project ID, then click 'Submit'. See the [New dataset page](./features/new_dataset.md) for what each field is for.

2. **Complete the curation log**: Once the tool finishes its checks, it redirects you to the checklist. Use the page to review the dataset and complete the curation checklist. See the [Checklist page](./features/checklist.md) for a description of each part of the page. These are the inputs you should provide in the checklist:
      1. **Status**: Select the appropriate status for each item (Pass, Follow-up, TBD, Not Applicable).
      2. **Comments**: Fill in your comments for the checklist item.
      3. **Time Spent**: Log the time spent on each item in the checklist. Click the start `▶︎` button to start the timer when you begin working on an item, and click the stop `■` button when you finish. The time will be logged in the "Time Spent" column. <br>If you forget to start the timer, you can also manually input the time spent in the "Time Spent" column in the format of MM:SS (e.g. 15:30 for 15 minutes and 30 seconds).
