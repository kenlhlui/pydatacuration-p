U of T user guide
==============================================================

This guide is for curators of the [U of T Dataverse collection](https://borealisdata.ca/dataverse/toronto) on Borealis. It covers the U of T setup and workflow: the Windows install, the Borealis settings and the U of T review process.

!!! note

    For a general setup on any system or Dataverse installation, see [Local setup (uv)](../local_setup/README.md) or [Container (Docker)](../container/README.md) instead.

## Get the tool running

- [Install on Windows](./installation.md): set up the tool on a Windows machine for the first time.
- [Restart the tool](./restart.md): update and start the tool again after the first install.

## Review a dataset

See [Review a dataset](./review_dataset.md) for the steps from starting a review to completing the checklist.

## Tool pages

There are several pages in the tool, each with a different function:

1. [Landing page](./features/landing.md): the home page of the tool, where you can start a new project, resume an existing project, or delete a project.
2. [New dataset page](./features/new_dataset.md): the page for starting a new project by providing the dataset information.
3. [Checklist page](./features/checklist.md): the page for reviewing the checklist items for a project.
4. [Resume project page](./features/resume.md): the page for resuming an existing project.
5. [Delete project page](./features/delete.md): the page for deleting an existing project.
